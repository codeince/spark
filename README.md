# ПРЕДЫСТОРИЯ

Давным-давно я решил сделать язык для создания текстовых приключений на Python(IgniTE).
Я просчитался с этим.
Потом я решил сделать генерацию текстовых историй с помощью ИИ на том же Python с LangChain.
Я назвал его Flamee, но мне не пришёлся по вкусу этот спагетти-код, что я написал.
Так что я написал этот :)

# ФУНКЦИИ

* Поддерживается два типа сохранения(JSON и байтовый RKYV)
* Через CLI вы можете настроить параметры запуска(`spark -h`)
* Поддержка многоязычности(русский и english доступны)
* Поддержка Markdown
* Данные для Windows версии(иконка, описание и т.д.)
* Поддержка команд для пользователя
* Поддержка собственного глобального промпта(ИИ будет придумывать истории по-другому)

# КОМАНДЫ ВВОДА

`/cancel` - удаляет содержимое этой и предыдущей строки
`/exit` - сохранить и выйти
`/next` - начать/продолжить генерацию истории
`/save` - сохранить историю в файл

# УСТАНОВКА

1. Скачать из [последнего релиза](https://github.com/codeince/spark/releases/latest) исполняемый файл и `prompt.txt`
2. Запустить [Ollama](https://ollama.com/download) и скачать любую нужную вам модель, **если вы хотите офлайн генерацию**
3. По умолчанию Spark настроен на Ollama, если у вас не Ollama, то при запуске передайте доп. аргументы(`--base-url {путь_до_api}`, `--api-key {api_ключ}`)
